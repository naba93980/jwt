# JSON Web Tokens

This repository contains  JWT based projects, starting with its fundamentals and progressing to token-based authentication. It serves as a reference for understanding how JWTs are used to establish identity and protect application resources.

## Topics Covered

- **JWT Fundamentals** — JSON Web Tokens and their purpose
- **Token-Based Authentication** — using tokens to authenticate requests
- **JWT Authentication** — exploring JWT-based authentication implementation
- **Protected Resources** — understanding how access to protected endpoints can be controlled using authentication tokens


## Purpose

This repository serves as a hands-on learning reference for understanding JWT concepts and how they fit into application authentication workflows.
